# 學習航圖｜分級免費評估

「學習航圖」是一個手機優先的親子學習評估網站。家長先選擇孩子的年級，再選擇相應的科目或試卷。系統每次會從較大的分級題庫中不重複地隨機抽出 20 題，完成後立即生成一份可下載及保存的 PDF 免費報告。

## 評估路線

| 學習階段 | 年級 | 可選免費評估 |
| --- | --- | --- |
| 小學 | 小一至小六 | 中文閱讀、英文、數學 |
| 升中準備 | 小五至小六 | 升中面試準備 |

英文把閱讀理解及寫作基礎整合為單一評估，涵蓋拼讀／詞彙、文法、文體、組織及修訂準備。英文中的寫作基礎題**不是**完整作文批改，亦不會把結果表示為校內成績、公開試結果或專業診斷。

## 題庫與報告

每份題組有 20 題。中文閱讀和數學每次從五個分組各抽四題；英文每次從五個閱讀和五個寫作基礎分組各抽兩題；升中面試從五組各抽四題。題庫以年級、試卷、能力面向、模組和難度標籤管理；抽題時會維持能力覆蓋，同時避免同一題目重複出現。免費報告包含總體答對比例、實際抽中範疇的成績、能力分項、最多三個可優先整理面向、兩星期起步建議及結果限制。

PDF 由瀏覽器端以 `html2canvas` 和 `jspdf` 產生，家長可直接下載。稱呼和地區只用於當前報告與 PDF 檔名／內容，這個靜態版本不會傳送或儲存資料。

## 本機啟動與驗證

```bash
pnpm install
pnpm dev
```

```bash
# 型別及生產建置
pnpm check
pnpm build

# 驗證 20 個可用年級—試卷組合均可隨機抽出 20 題
pnpm verify:graded

# 模擬完整評估、報告生成與 PDF 下載
pnpm smoke:graded-pdf
```

## 重要檔案

| 檔案 | 用途 |
| --- | --- |
| `client/src/data/gradedAssessment.ts` | 年級、試卷、題庫範本及 20 題隨機抽題規則 |
| `client/src/pages/Home.tsx` | 年級入口、20 題流程、免費報告及瀏覽器端 PDF 下載 |
| `GRADED_RANDOM_PDF_SPEC.md` | 小學分級、單一英文讀寫整合、隨機抽題與 PDF 報告的產品規格 |
| `scripts/verify-graded-random.mjs` | 年級／試卷組合、題數、重複和能力覆蓋驗證 |
| `scripts/smoke-graded-pdf.mjs` | 完整前端流程與 PDF 下載端到端測試 |

## 正式營運前

正式使用前，應由各科具教學經驗的人員覆核題目、各年級難度、干擾選項和參考答案，並持續擴充題庫。若要收集家長聯絡資料、管理合作補習社或追蹤轉介，必須另行加入授權後端、私隱政策、明確同意、資料保留期限和資料存取程序。
