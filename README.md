# 學習航圖｜多科學習小測驗

這是一個手機優先的互動學習評估網站，協助家長和學生用 5 條問題整理現時較值得討論的學習方向。使用者可按學習階段選擇相應科目，完成後以最少資料解鎖即時分析報告，並按香港所在區域查看合作補習社**示範資料**。

## 已完成的評估路線

| 學習階段 | 路線 |
| --- | --- |
| 小學全科 | 中文、英文、數學 |
| 升中面試 | 自我介紹、聆聽、應對、協作與表達準備 |
| 初中 | 中文、英文、數學、Science |

每條路線均提供五題評估、逐題進度、針對答題面向的學習建議，以及按**所選階段、科目和所在地區**排序的合作機構示範推薦。升中面試題目用來提示溝通準備方向，並不預測面試結果。

## 本機啟動

```bash
pnpm install
pnpm dev
```

用以下指令進行型別檢查與生產建置：

```bash
pnpm check
pnpm build
```

## 合作補習社與個人資料

`client/src/pages/Home.tsx` 內的合作補習社為**示範資料**，並非真實合作夥伴。正式上線前，請將每間機構的真實名稱、地區、可服務學習階段、科目、教學形式、聯絡連結和優惠條款替換到 `PARTNERS` 資料中。

目前的家長稱呼、WhatsApp 號碼及地區只在瀏覽器當前頁面的記憶體中使用，**不會傳送或儲存**。如要正式收集個人資料，必須先接駁經授權的安全表單或後端端點，並加入清楚的私隱政策、明確同意、保留期限與資料存取程序。

## 重要檔案

| 檔案 | 用途 |
| --- | --- |
| `client/src/pages/Home.tsx` | 八條測驗路線、題庫、評分、報告和地區推薦邏輯 |
| `client/src/index.css` | 「學習航圖」視覺系統、分流目錄及響應式樣式 |
| `QUIZ_CATALOG.md` | 各階段與科目的題庫、能力標籤及報告規則 |
| `ideas.md` | 已選定的品牌與設計方向 |
| `IMPLEMENTATION_NOTES.md` | 資料解鎖、私隱及合作資料處理原則 |

## 下一步

正式營運前，請提供合作補習社的真實名單及聯絡連結。若需要儲存家長資料、管理合作機構、發送 WhatsApp／電郵或追蹤轉介，應另行加入具權限、私隱及保安措施的後端流程。
