# 學習航圖｜英文基礎小測驗

這是一個手機優先的互動英文基礎小測驗網站，供家長與學生以 5 條問題整理目前的學習方向。完成答題後，使用者可填寫最少資料以解鎖即時分析報告，並按香港所在區域查看已排序的合作補習社**示範資料**。

## 已完成的首版體驗

網站包含小測驗首頁、五題英文評估、逐題進度、家長資料解鎖界面、三種結果層級、按答錯能力面向組合的學習建議，以及按十八區排序的合作機構推薦。首頁及報告採用「學習航圖」設計系統：米霧紙張底色、墨綠閱讀骨架、航標珊瑚行動訊號與非對稱的編輯式版面。

## 本機啟動

```bash
pnpm install
pnpm dev
```

用以下指令進行型別檢查與生產建置：

```bash
pnpm check
pnpm build
```

## 合作補習社與個人資料

`client/src/pages/Home.tsx` 內的合作補習社為**示範資料**，並非真實合作夥伴。正式上線前，請將每間機構的真實名稱、地區、年級、服務形式、聯絡連結與優惠條款替換到 `PARTNERS` 資料中。

目前的家長稱呼、WhatsApp 號碼、年級及地區只在瀏覽器當前頁面的記憶體中使用，**不會傳送或儲存**。如要正式收集個人資料，必須先接駁經授權的安全表單或後端端點，並加入清楚的私隱政策、明確同意、保留期限與資料存取程序。

## 重要檔案

| 檔案 | 用途 |
| --- | --- |
| `client/src/pages/Home.tsx` | 小測驗、評分、報告及地區推薦邏輯 |
| `client/src/index.css` | 「學習航圖」視覺系統與響應式樣式 |
| `ideas.md` | 已選定的品牌與設計方向 |
| `IMPLEMENTATION_NOTES.md` | 題目、報告、私隱及合作資料規則 |
